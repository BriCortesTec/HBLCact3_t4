Sistema de administración

Bienvenido al sistema de gestión de productos y categorías. Desde este panel puedes consultar y administrar la información registrada en la base de datos.

Menú principal

Gestión de categorías

Registra nuevas categorías, consulta las existentes, modifica sus datos o elimínalas.

Gestión de productos

Registra productos, asigna una categoría y administra los productos existentes.

Información del sistema

Proyecto: Spring Boot - Actividad 3

Base de datos: MariaDB / MySQL

Arquitectura: API REST
